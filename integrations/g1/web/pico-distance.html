尚未设置独立的测量起点

先保持测量起始姿势，再点击排队；下一组有效输入将作为起点。若当前没有数据，返回 XRoboToolkit 并保持该姿势。

与电脑端使用同一个身体姿势

  1. 如需观察 PICO 输入，先在电脑端采集校准原点；保持该姿势，再点击本页「设置测量起点」。两处起点分别记录，本页归零不影响电脑校准。
  2. 按你指定的方向和填写的实际距离移动手腕。每个方向都先回到同一原点，保持头部面向正前方、手腕朝向不变；无需等待读数达到某个值。
  3. 分量正数对应原始坐标的前／左／上，负数对应后／右／下；坐标以起点时头部朝向冻结。这些未校准分量不用于验证你实际移动的方向。

以你确认的实际距离和方向为准。PICO 数值仅供观察原始输入，不作为校准目标或通过条件。若需核对实际距离，请使用实体尺；PICO 读数不能替代实体尺。

本页仅显示输入并设置独立测量起点，不修改电脑校准结果，也不控制机器人。数据中断或起点失效时，数值自动隐藏。

若打开头显浏览器后数据停止，可使用上方「等待输入后归零」，再回到 XRoboToolkit，保持应用前台并通过下方 RemoteVision 查看距离。浏览器与跟踪应用能否同时运行，需以头显实际状态为准。

在 XRoboToolkit 内查看距离

保持 XRoboToolkit 前台，启用 Head / Object / Send。在 RemoteVision 中选择电脑 读取中，设置为 ZEDMINI / H.264 / 2560 × 720。
