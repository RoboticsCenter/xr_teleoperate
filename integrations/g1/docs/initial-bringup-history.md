# Initial bring-up context

The integration began with read-only G1/BrainCo diagnostics and a single PICO
wrist Tracker, then added two arms, independent glove calibration and hand
following, PICO controllers, headset-relative control and a web dashboard.

The original installation's session chronology, operator conversations and
hardware captures are not part of this export. Historical network addresses and
adapter assignments must not be used to infer a new installation's wiring.

Use [the dashboard guide](teleop-dashboard.md), [network configuration](network-config.md)
and [the implementation summary](../PLAN.md). Software tests and previous device
observations are not a substitute for verifying the actual deployment.
