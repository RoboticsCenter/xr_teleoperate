# 网页手套校准

入口：<http://127.0.0.1:8025/> 的手套校准区域。左、右分开完成。用户当前只要求上线功能；不会自动执行真实校准。

## 使用步骤

1. 戴好需要校准的一侧手套。在该侧点击创建或重新校准个人手型。这会保留已有 SDK 数据、暂停手套读取，并启动 Wuji 自带手型校准。手指输出需要先停止。
2. 按页面当前姿态说明完成六个 SDK 姿态。SDK 自动判断并推进，页面显示进度；可随时取消，不需要另开终端。完成后自动刷新模型并启动该侧原始读取器。
3. 已有可用个人模型时可以直接点该侧的启动输入按钮。此按钮只读手套，不启动 PICO 或机器人手部服务。
4. 手掌展开、手指并拢，点采集张开并保持约2秒。等待显示样本数后，握完整拳、拇指跨在手指前方，点采集握拳并保持约2秒。
5. 成功后自动保存该侧映射并显示六通道预览。慢慢张开、半握、握拳观察方向；预览不会给机器人发目标。控制按钮与校准按钮分开。

同一时间只进行一个 SDK 模型校准，因为 SDK 用户与模型存储共享。模型校准期间暂停两只读取器，完成后启动所选侧；另一侧可单独恢复读取。手臂/PICO不因校准操作自动启停。

## 数据与复用

固定用户`brainco-teleop`；左SN `WG1JA06260822033`，右SN `WG1KA06260821549`。SDK工具在开始前核对设备侧别，并保留用户/模型备份。SDK模型保存在现有 Wuji 用户目录；网页的开合映射分别保存`config/hand-calibration-left.json`、`config/hand-calibration-right.json`，覆盖前备份旧文件。

手套读取、confidence过滤、六通道readings/calibrate/closure/targets以及实际控制中的LowPass/step_limited直接复用原`brainco-wuji-teleop`。开合采样沿用原算法的中位数、非空样本要求与MIN_SPAN，不添加另一套质量阈值。预览是原映射目标，未包含机器人实测步长限制，因此不会冒充实际手部反馈。

采样绑定侧别、SN、SDK用户、模型哈希与reader会话；换模型、重启读取器或取消后需要重新采张开，避免拼接不同身份的开合数据。输入失败直接显示原因，不重复自动扫描。
