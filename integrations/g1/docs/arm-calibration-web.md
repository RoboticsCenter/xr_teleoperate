# 手臂方向与距离校准

在 http://127.0.0.1:8025/ 的“手臂方向与距离校准”中操作。以操作者填写的实际移动距离及选择的前、左、上方向为基准，校正左右臂的平移。PICO 位移是待校正的原始输入，不能用来否定操作者的实际移动。采集、拟合和保存不构造 G1 控制器，也不启动机械手输出。

## 现场步骤

1. 停止手臂和机械手跟随，确认网页所选左右 Tracker 正确。在 PICO 开启 Head、两只 Object Tracker 和 Send，电脑地址为 192.168.31.92。
2. 填写你确认的每个方向实际移动距离，默认 20 cm（可用尺确定）；不要根据 PICO 显示的数值决定何时到达。面向身体正前方，双腕保持舒适姿态，点击“采集原点”。原点采集后距离固定；重新设置距离需重置本轮采集。
3. 所选双腕从原点向身体正前方移动该距离，保持手腕朝向，点击“采集向前”。
4. 回到相同原点，再向身体左侧移动该距离，点击“采集向左”。
5. 回到相同原点，再向上移动该距离，点击“采集向上”。每次采集时保持姿态，可由旁人操作按钮。
6. 确认自己填写的实际距离和所做方向，然后点击“保存”。页面上的 PICO 原始读数仅供对照，无需与实际距离一致。重置仅清除本轮未保存采集，不删除已有校准。
7. 下次 LAUNCH/START 使用保存的校准。START 时头部和身体仍朝同一正前方向，并保持准备作为新零点的双腕姿态；START 会重新捕获机器人的实测关节 FK 与腕部零点。

未收到 Tracker 数据时不能生成真实标定。LAUNCH 已独立于输入，不再等待 Head/Object/Send 或在 12 秒后退出；START 缺数据时留在 READY，收到数据后再次点击 START。

## 保存和映射

保存位置为 `config/arm-calibration.json`，覆盖前会备份。采集绑定所选手臂、Tracker SN、安装偏移和本次输入会话；采集中切换设备或重连会要求重新采原点。保存后的修正相对采集时的头部前向表达，下次 START 使用当时的新头部前向，不直接复用旧世界坐标。单臂重新校准会保留身份、安装偏移仍匹配的另一侧记录。模拟校准不写生产文件，生产入口拒绝模拟记录。

每侧将三个 PICO 原始位移映射到操作者指定的实际方向和距离。新增的三轴平移修正可处理各轴比例不同、方向串扰和反向；修正只作用于相对机器人初始末端的平移。腕部姿态仍通过正交旋转及原分支 `IncrementalWrist` 的相对旋转计算，平移矩阵不作用于姿态。已有单倍率校准兼容，未提供校准的侧保持原分支映射；原 vendor 和 Wuji 手指算法不改。

不再按 PICO 原始位移不足 3 cm、三轴不正交、镜像、方向误差、距离误差超过 25% 或校正比例超出 0.1–10 拒绝本次校准。用户填写的实际距离保持 3–100 cm。仍需要有效的真实输入、同一 Tracker 绑定与会话，以及可以求解的三组独立位移；完全没有位移或三组位移重合时无法计算三维修正，不会伪造结果。诊断数值只供参考，不作为操作者动作合格与否的判据。

## 验证范围

自动化测试覆盖从合成三轴采集、保存、重载到原映射消费，包含不同左右比例、坐标旋转、安装偏移、PICO 世界整体偏航变换，以及模拟网页完整采集流程。它们不等于实物精度验收。

这个流程不能估计机器人关节零位、错误的机械装配或真实掌心 TCP，也不会扩大机器人的可达范围。后续运行日志已增加原始 Tracker 姿态、头部姿态、笛卡尔目标和时间信息，便于区分输入偏差、IK 约束与反馈偏差。
