## 16:57 右手可能位于 G1 网口支路

用户描述可能指共享 USB Hub，也可能指共享以太网二层网络；两者不能仅凭“adapter 接 adapter”相互等同。当前 USB 树仍只有两张已知网卡，不能由此确认或否定 G1 网口后是否还有交换机/右手分支。

本机实际路由：

```text
192.168.1.101 dev enx6c1ff772bfe8 src 192.168.1.250
```

因此普通 `ping 192.168.1.101` 会走左手网口，不能证明另一个 `enx6c1ff762d908`（G1 网口）支路上不存在右手。原路由和 G1 地址保持不变，没有为 G1 网口添加第二个 `192.168.1.0/24`。

本轮尝试对 **G1 网口**、**固定一个地址 `192.168.1.101`** 做定向 ARP：进程没有 `CAP_NET_RAW`，创建 ARP 原始 socket 返回 EPERM；本机未安装独立 `arping`，但 BusyBox 有该功能。一次非交互 `sudo -n ... arping` 因本机需要交互认证而未启动，**没有发送 ARP 包**。此结果是权限限制，不是右手无应答。

以下是当时准备的本机单地址命令，保留作记录；后续已由 PC2 完成替代探测，当前无需再次执行：

```bash
sudo /usr/bin/busybox arping -D -c 1 -w 2 \
  -I enx6c1ff762d908 -s 0.0.0.0 192.168.1.101
```

这是指定接口的地址探测，不改变 IP、路由或其他项目。`-D` 模式若收到目标回应，退出码 **1** 表示发现地址占用，不能当普通失败；需保留输出中的回应 MAC。得到 MAC 后仍需核对手套 SN，不能凭 MAC 直接当作已确认身份。若后续需要只针对右手地址建立 `/32` 来源与 host route，由主代理结合现场结果决定；此代理不修改网络。

证据：[定向探测权限与路由记录](../diagnostics/wuji-right-g1-arp-2026-11-11.json)。未动左手 `192.168.1.250/24`、G1 原地址或 Piper 项目；无需再次确认两手供电。

## 官方连接要求与本机差异

Wuji 官方手套准备流程是：**采集主板 → 专用 USB-C 转网口供电适配器 → 网线与供电线**。专用 C-C 线两端的白色矩形标记必须保持相同朝向；接反可能只供电而没有数据。[官方使用前准备](https://docs.wuji.tech/docs/zh/wuji-glove/latest/getting-started)

手套出厂采用静态 IPv4，左手 `192.168.1.100`、右手 `192.168.1.101`，不用 DHCP。电脑直连时需有相应网段地址，例如未占用的 `192.168.1.50/24`。这与 **Zenoh 宿主 `192.168.31.101`** 是两个不同概念；不要混淆 `.1.101` 与 `.31.101`。[官方设备发现与连接](https://docs.wuji.tech/docs/zh/wuji-sdk/latest/device-connection)

新增手套网卡前的本机网卡：

| 网卡 | IPv4 | 已知用途 |
| --- | --- | --- |
| `wlp192s0` | `192.168.31.92/24` | Wi-Fi，当前 Zenoh 对端所在网段 |
| `enx6c1ff762d908` | `10.42.0.1/24`、`192.168.123.10/24` | UGREEN，用户确认直接连 G1 |

早期没有 `192.168.1.x/24` 地址，因此当时不具备按出厂地址直接连接手套的网卡配置；后来新增独立手套网卡，最新状态见本文开头。共享宿主可以让 SDK 通过 Zenoh 发现条目，不要求本机与物理手套直接处于同网段。本代理没有更改网卡地址、路由或共享设置。不能把 G1 直连网线自动当作手套链路，也不要照抄官方示例里的清空地址命令而破坏当前 G1 网络。

SDK `scan()` 的公开 Python 签名无网卡参数，文档声明扫描 USB 与 UDP；本机实测还返回 Zenoh 条目。安装包 `.pyi` 中 `TransportType` 仅列 `Usb` / `Udp`，因此工具保存实际 `str(transport_type)`，没有假定只会出现这两种值。官方说明 `enable_bridge=True` 默认允许其他进程/主机访问由当前 SDK 实例共享的设备；这与实测 Zenoh 发现相符，但官方公开页面未完整描述 Zenoh discovery 的型号字段行为。[官方连接选项](https://docs.wuji.tech/docs/zh/wuji-sdk/latest/device-connection#连接选项)

USB 扫描也服务于 Wuji 机械手等型号，并不代表 Wuji Glove 的专用网口适配器应该在电脑上枚举为手套 USB。当前本机 USB 清单没有直接证明手套已连入；不将这一点单独解释为手套断电。

## 可重复命令

